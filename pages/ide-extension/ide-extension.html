inventory_2 Installation

From the VS Code Marketplace

  1. Open Extensions
    Press Ctrl+Shift+X (or Cmd+Shift+X on Mac) to open the Extensions panel
  2. Search for "Promptroot"
    Type "Promptroot" in the search bar and click Install
  3. Sign In
    Open the Command Palette (Ctrl+Shift+P) and run Promptroot: Sign In

From the Command Line

  1. Install via CLI
    Run: code --install-extension promptroot.promptroot-vscode

rocket_launch How to Use

  1. Open any workspace in VS Code — look for "PROMPTROOT ASSETS" in the Explorer sidebar
  2. Sign in with GitHub via the Command Palette (Promptroot: Sign In) — same account as the web app
  3. Create a prompt with Promptroot: Create New Prompt Asset — choose a template, fill in metadata, and confirm
  4. Queue it up — right-click any prompt asset → "Add to Jules Queue" or use batch mode
  5. Track progress — watch the "JULES SESSIONS" tree view for real-time status and PR links

build Troubleshooting

Extension not appearing after installation?

Try reloading the window: Ctrl+Shift+P → "Developer: Reload Window". Verify the workspace contains a prompts/ folder or run "Promptroot: Initialize Workspace".

Authentication not working?

Ensure your GitHub account is active. Try signing out and back in. Check the Output panel (View → Output → "Promptroot") for details.

Queue or sessions not loading?

Verify you're signed in (check the status bar). Use "Promptroot: Show Connection Status" to check Firebase connectivity.

Need more help?

Visit promptroot.ai or open an issue on GitHub.
