inventory_2 Setup — Relay Mode (Recommended)

Step 1 — Install OpenClaw

  1. Install the OpenClaw daemon on your machine and ensure Brace is configured
  2. Verify the gateway is running
    systemctl --user status openclaw-gateway should show active (running)

Step 2 — Generate an Agent Token

  1. Open your Profile page and scroll to the Agent API section
  2. Enter a label (e.g. OpenClaw dev) and click Generate Token
  3. Copy the token immediately — it is only shown once

Step 3 — Configure OpenClaw

  1. Add the token to OpenClaw's environment
    Append to ~/.openclaw/.env: 
    PROMPTROOT_AGENT_TOKEN=pra_...
  2. Enable the promptroot-relay plugin
    In ~/.openclaw/openclaw.json, add under "plugins": 
    "promptroot-relay": { "enabled": true }
  3. Restart the gateway
    systemctl --user restart openclaw-gateway

Step 4 — Connect in PromptRoot

  1. Sign in above, paste your pra_... token into the Agent Token field, and click Save
  2. The status card above will update to OpenClaw Connected
  3. Open any prompt and click Run in Brace to verify the connection

settings Advanced — Custom URL Mode

For self-hosted setups using a Cloudflare Tunnel or static public URL pointing at your OpenClaw gateway. Requires a valid HTTPS endpoint.

  1. Set up a Cloudflare Tunnel
    Run cloudflared tunnel run pointed at your local OpenClaw gateway port
  2. Select "Use my own URL" in the connection form above, enter your gateway URL and token, and click Save

build Troubleshooting

"Run in Brace" button not appearing?

Sign in and save a connection using the form above. The button appears on all prompts once a connection is saved.

Connection saved but no response arrives?

Check the gateway is running: systemctl --user status openclaw-gateway. Verify PROMPTROOT_AGENT_TOKEN is in ~/.openclaw/.env and the gateway was restarted after adding it.

Token rejected (4003 Invalid token)?

The token in ~/.openclaw/.env must match the one saved in PromptRoot. Generate a fresh token on the Agent API page, update both places, and restart the gateway.

Infinite reconnect loop in gateway logs?

Happens when promptroot-relay is enabled in both [plugins] and [gateway] sections of openclaw.json. Remove the duplicate entry and restart.
