Authenticate requests with: Authorization: Bearer <token>

Endpoints

  • GET /prompts — list prompt files
  • GET /prompts/:path — fetch prompt content
  • POST /prompts/render — render template with variables
  • GET /queue — list Jules queue items
  • POST /queue — add item to queue
  • PATCH /queue/:id — update queue item
  • DELETE /queue/:id — remove queue item
  • GET /sessions — list Jules sessions
  • GET /webclips — list web clips
