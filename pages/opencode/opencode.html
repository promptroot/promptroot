inventory_2 Setup Guide

Step 1 — Start the OpenCode Server

  1. Start the headless server in your terminal. You must specify the CORS origins so the PromptRoot browser app can communicate with it: 
    opencode serve --cors http://localhost:3000 --cors https://promptroot.ai
  2. By default, the server runs on port 4096. You can customize the port by adding the --port flag.

Step 2 — Configure PromptRoot

  1. Click the Configure button above.
  2. Enter your Server URL (e.g. http://localhost:4096) and password/token if Basic Auth/Tokens are set up via environment variables.
  3. Click Save.
